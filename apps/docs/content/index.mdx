ProxyHubb is a Solana-settled residential proxy marketplace. Buyers pull traffic through the edge gateway; providers run a tunnel daemon and earn from usage.

| Surface | URL |
|---------|-----|
| App | [proxyhubb.com](https://proxyhubb.com) |
| Control API | [api.proxyhubb.com](https://api.proxyhubb.com) |
| Buyer proxy | `proxy.proxyhubb.com:8090` (HTTP CONNECT / SOCKS5) |
| Docs | [docs.proxyhubb.com](https://docs.proxyhubb.com) |
