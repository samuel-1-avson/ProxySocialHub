Marketplace purchases lock buyer SOL in a Solana escrow PDA until the order is active (and later settled). Credentials for CONNECT are issued only when the order **and** session are ready.

## In plain English

An **escrow** is a locked box. When you buy from the marketplace, your money goes into the box, not to the provider. When you're done, the box pays the provider for exactly what you used and gives you back the rest.

<MoneyFlow />

### The life of an order

<Flow caption="You get your proxy username and password at step 3, once the money is safely in the box.">
  <FlowStep icon="calendar" title="1. Order created">You pick a listing. Status: <code>pending</code></FlowStep>
  <FlowStep icon="wallet" title="2. You pay">Your wallet sends SOL to the box. Status: <code>pending_payment</code></FlowStep>
  <FlowStep icon="key" title="3. Ready" arrow="confirmed">Payment seen. You get your key. Status: <code>active</code></FlowStep>
  <FlowStep icon="paid" title="4. Settled" arrow="used up / done">Provider paid, rest refunded. Status: <code>completed</code></FlowStep>
</Flow>

If an order is never paid, or expires unused, the money goes back to you (`refunded`).

## Happy path

```text
POST /v1/orders
    → pending
POST /v1/orders/{id}/pay/solana
    → pending_payment  (+ program_id, escrow_pda, amount_lamports)
Buyer signs & submits on-chain escrow fund
POST /v1/orders/{id}/confirm-escrow
    → active  (session active)
GET /v1/orders/{id}/credentials
    → username / password for proxy.proxyhubb.com:8090
```

`pay/solana` may return **402** if the buyer cannot fund. Credentials before ready → **409** with `order_not_ready` (`retryable: true` when applicable).

## Status machine (simplified)

| Status | Meaning |
|--------|---------|
| `pending` | Order created; not funded |
| `pending_payment` | Awaiting / confirming on-chain escrow |
| `active` | Escrow confirmed; session usable; credentials available |
| `completed` | Usage finished / settled path |
| `disputed` | Dispute open |
| `cancelled` / `refunded` | Terminal without (or after) refund path |

Credentials are available when status is in `{active, completed}` **and** the linked session is active. Details: [Orders](/docs/marketplace/orders).

## What buyers should know

- Escrow amounts are in **lamports / SOL** on Solana **devnet** for public testnet
- Confirm may take `{ tx_signature }` or rely on a chain listener: always poll status if UX is async
- Dev-only shortcuts (`activate-dev`, sandbox) require `PROXYHUB_ALLOW_DEV_ESCROW_ACTIVATE=true` and must not be assumed in production
