## 📋 How to Participate

### Step 1: Join the Program
1. Join Discord: https://discord.gg/proxyhubb
2. Join #beta-testers channel
3. Fill out registration form: [Link]
4. Get your tester role

### Step 2: Set Up DevNet Wallet
```bash
# Install Solana CLI
sh -c "$(curl -sSfL https://release.solana.com/v1.17.0/install)"

# Create wallet
solana-keygen new --outfile ~/.config/solana/devnet.json

# Switch to DevNet
solana config set --url devnet

# Get free DevNet SOL
solana airdrop 10
```

### Step 3: Connect to ProxyHubb
1. Visit: https://devnet.app.proxyhubb.com
2. Connect your DevNet wallet
3. Complete onboarding tutorial
4. Start testing!

## 🐛 Bug Reporting

### How to Report

1. **Check if already reported**: Search Discord #bug-reports
2. **Use template**: Follow format below
3. **Submit**: Post in #bug-reports with [BUG] prefix

### Bug Report Template

```markdown
**Reporter:** @username
**Severity:** [Critical/High/Medium/Low]
**Component:** [Escrow/Jury/Multi-sig/UI]

### Summary
Brief description

### Steps to Reproduce
1. Step one
2. Step two
3. Step three

### Expected Result
What should happen

### Actual Result
What actually happens

### Screenshots
[Attach images]

### Environment
- Wallet: Phantom/Solflare/Other
- Browser: Chrome/Firefox/Safari
- OS: Windows/Mac/Linux
- Transaction ID: [If applicable]

### Additional Notes
Any other context
```

### Bug Severity Guidelines

| Severity | Criteria | Example |
|----------|----------|---------|
| **Critical** | System broken, funds at risk | Can't withdraw, calculation errors |
| **High** | Major feature broken | Settlement fails, can't vote |
| **Medium** | Minor feature broken | UI glitch, slow loading |
| **Low** | Cosmetic issue | Typo, misalignment |
