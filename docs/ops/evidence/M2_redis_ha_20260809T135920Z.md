## Scope

Backlog M2 / audit EV-05: Redis SPOF for sessions + metering.  
**Chosen path:** on-VM Redis Sentinel + HAProxy master gateway (no Memorystore spend on Phase A). Same-VM host SPOF remains; Memorystore is the paid cross-VM upgrade.

## Topology

- `redis` (master) + `redis-replica` with AOF
- 3× `redis-sentinel-*` (quorum 2, `mymaster`)
- `redis-proxy` (HAProxy) — apps use `REDIS_URL=…@redis-proxy:6379`
- Redis containers keep DNS after `SHUTDOWN` via `sleep infinity` wrapper (avoids Sentinel TILT)

## App wiring

`control-api` / `edge-gateway` compose overlay forces `REDIS_URL` → `redis-proxy`.  
Go also supports optional `REDIS_SENTINEL_ADDRS` FailoverClient (unused when proxy is primary).

## Not claimed

- Cross-VM / zonal HA (still single GCE VM)
- Memorystore managed SLA
- Zero-downtime for in-flight multiplexed connections during the ~few-second failover window (spill/hydrate remain the safety net)
