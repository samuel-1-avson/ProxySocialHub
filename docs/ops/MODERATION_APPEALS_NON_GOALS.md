# Moderation appeals — non-goals (Wave 3.4)

Companion to [ADR 0008](../adr/0008-moderation-appeals.md).

Wave 3.4 **does not** deliver:

| Claim | Why deferred |
|-------|----------------|
| Live seller appeal API | Design-only ADR |
| Jury voting on delists | Reuse dispute-jury later |
| On-chain listing PDAs | Wave 4+ / separate epic |
