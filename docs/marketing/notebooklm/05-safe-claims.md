# Safe Claims Guide for ProxyHubb Video

NotebookLM should treat this as a guardrail document. Prefer understatement over hype.

## Safe claims (use freely)
- ProxyHubb is a Solana-settled residential proxy marketplace
- Buyers discover capacity and route traffic through an edge gateway
- Providers run a node / CLI, publish listings, and can earn from usage
- Usage is designed to be metered at the edge
- Access is wallet-native via Solana
- There is a public explorer for network inspection
- There are docs and official SDKs (Python, Node.js, Go)
- The product is early and still shipping
- The founding motivation is clearer markets and less opaque bandwidth buying/selling

## Soft / careful claims (okay with hedging)
- “Designed for transparent pricing and auditable usage”
- “Wallet-native settlement on Solana”
- “A two-sided marketplace for residential bandwidth”
- “Quiet infrastructure”
- “Still early / emerging / shipping in public”

## Do not claim as proven facts
- 99.9% uptime
- sub-50ms latency as a guaranteed SLA
- Fully trustless architecture
- Fully decentralized production settlement with no platform role
- Large user counts, revenue, or market share
- Agents marketplace as a live paid execution product
- ISP-targeted routing as a shipped capability
- “Production-hardened finance-grade” custody
- Guaranteed passive income for providers

## Words to prefer
- marketplace
- residential bandwidth / residential proxy capacity
- edge metering
- wallet-native
- providers / nodes
- public explorer
- early / still shipping
- quieter / clearer rules

## Words to avoid unless carefully explained
- trustless
- revolutionary
- guaranteed
- passive income overnight
- disrupt everything
- fully decentralized end-to-end (too strong for current maturity)

## Brand consistency
- Prefer **ProxyHubb** in narration
- Website: proxyhubb.com
- Optional phrase: “Quiet infrastructure for residential proxy bandwidth”
