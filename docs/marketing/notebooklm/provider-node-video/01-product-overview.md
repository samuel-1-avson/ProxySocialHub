# ProxyHubb — Product Overview (Provider Video Pack)

## One-sentence definition
ProxyHubb is a Solana-settled residential proxy marketplace. Buyers discover capacity, fund orders, and pull traffic through an edge gateway. Providers run a tunnel node that advertises capacity and earns from metered usage.

## Brand
- Public product name: ProxyHubb
- Website: https://proxyhubb.com
- Docs: https://docs.proxyhubb.com
- Positioning line: Quiet infrastructure for residential proxy bandwidth
- Tagline used on the product: The decentralized bandwidth marketplace

## What problem it solves
Residential proxy bandwidth is widely used for research, testing, automation, and other internet work that needs real household network routes. The usual buying experience is closed and opaque. People with spare capacity also lack a clean marketplace path to publish and earn without becoming a full infrastructure company.

ProxyHubb turns that into a two-sided market with clearer rules.

## Who this video is about
This video focuses on **providers** — people who run nodes, publish listings, and supply the residential routes buyers purchase.

Buyers, developers, and explorer observers still exist in the product, but they appear here mainly to show how provider capacity gets used.

## Core value props (provider angle)
- Publish residential capacity into a real marketplace
- Run a provider node / CLI that tunnels into the network
- Join from ordinary home networks because the tunnel is outbound
- Earn from usage designed to be metered at the edge
- Settle in a wallet-native way on Solana
- Keep the network inspectable through a public explorer

## Product surfaces that matter for providers
| Surface | What it is |
|---------|------------|
| Web app | Provider setup, nodes, CLI downloads, listings, earnings |
| Provider node / CLI | Daemon that tunnels capacity into the network |
| Edge gateway | Admits buyer sessions and meters bytes; receives provider tunnels |
| Marketplace | Where listings are discovered and purchased |
| Control API | Auth, nodes, tokens, listings, wallets, provider ops |
| Explorer | Public view of nodes, sessions, and network activity |
| Docs | Provider CLI / node guidance |

## What makes this different from a typical proxy vendor
Typical vendors sell access to a closed pool with opaque invoices. Providers are often invisible.

ProxyHubb is designed as a marketplace:
- buyers browse and purchase capacity
- providers publish supply by running a node
- usage is measured at the edge
- settlement is wallet-native
- network activity can be inspected publicly

## Honest maturity note
ProxyHubb is a live, early-stage product that is still shipping. Marketplace flows, buyer CONNECT, provider tunnels, docs, SDKs, and explorer surfaces exist. Describe it as an emerging bandwidth marketplace and builder project — not as a finished, finance-grade monopoly or a fully trustless system.
