# Social & Community Layer – ProxySocialHub

This document captures **all social, community, and transparency features** discussed in our conversation. These features transform ProxySocialHub from a simple proxy marketplace into a **true social platform and economic network**.

---

## 1. Purpose of the Social Layer

The Social Layer exists to:
- Build **trust** between buyers and providers
- Encourage **long-term relationships**, not one-off transactions
- Enable **group-based selling (Clans)**
- Increase **platform stickiness and engagement**
- Provide **transparent performance insights** without violating privacy

---

## 2. User & Provider Profiles

### 2.1 Public Profiles
Each user (buyer or provider) has a profile containing:
- Username / Display name
- Role (Buyer, Provider, Clan Admin)
- Reputation score
- Badges & achievements
- Join date
- Activity summary (non-sensitive)

> ❗ Real names, IP addresses, and personal identifiers are never exposed.

---

## 3. Provider Hardware & System Transparency

### 3.1 Provider Hardware Profile (Opt-in)
Providers can **choose** to share system specs to increase buyer confidence.

Shared attributes:
- CPU model & core count
- Available RAM
- Storage type (HDD / SSD)
- Network type (Fiber / Mobile / WiFi)
- Estimated bandwidth capacity
- Operating system

### 3.2 Live Performance Metrics (Aggregated)
Collected via Provider Agent:
- Uptime percentage
- Average latency
- Bandwidth availability
- Error rate
- Session success rate

> 🔒 No payload data, browsing history, or destination content is ever collected.

---

## 4. Quality Scoring & Rankings

### 4.1 Provider Performance Score
A composite score derived from:
- Hardware strength
- Historical uptime
- Buyer feedback
- Abuse reports (negative weight)

### 4.2 Rankings
- Top Providers (daily / weekly / monthly)
- Top Clans
- Most Reliable Proxies
- Fastest Nodes

Rankings are **algorithmic and tamper-resistant**.

---

## 5. Social Connections

### 5.1 Friend System
- Send / accept friend requests
- View friends’ public activity
- Direct messaging enabled by default between friends

### 5.2 Follow System
- Follow providers or clans
- Get notified about:
  - New proxy availability
  - Performance milestones
  - Clan openings

---

## 6. Messaging & Communication

### 6.1 Direct Messaging (DM)
- Buyer ↔ Provider
- Provider ↔ Provider
- End-to-end encrypted
- Rate-limited to prevent spam

### 6.2 Clan Chats
- Private chat rooms per clan
- Admin / Moderator roles
- Announcement-only channels

### 6.3 Work / Negotiation Chats
- Temporary chats linked to:
  - Proxy deals
  - Clan invitations
  - Enterprise contracts

Chats auto-expire unless archived.

---

## 7. Clans (Group-Based Selling)

### 7.1 Clan Structure
- Clan Owner
- Clan Admins
- Clan Members (Providers)

### 7.2 Clan Proxy Pooling
- Providers combine proxies
- Sold as **one logical provider**
- Load-balanced across members

### 7.3 Revenue Distribution
- Usage-based earnings
- Automatic revenue split
- Transparent breakdown per member

---

## 8. Discovery & Search

Users can search for:
- Providers
- Clans
- Proxy types (mobile, residential)

Filter options:
- Location
- Performance tier
- Price range
- Reputation score
- Hardware capability

---

## 9. Incentives, Badges & Gamification

### 9.1 Badges
- Verified Provider
- High Uptime (99%+)
- Trusted Seller
- Clan Leader

### 9.2 Incentives
- Fee discounts
- Boosted visibility
- Priority routing

---

## 10. Privacy & Monitoring Boundaries

### What IS monitored:
- Bandwidth usage
- Session duration
- Performance metrics

### What is NEVER monitored:
- Traffic content
- Destination URLs
- Personal files
- User identity behind traffic

All monitoring is:
- Purpose-limited
- Aggregated
- Auditable

---

## 11. Moderation & Safety

- Reporting system (abuse, fraud)
- Automated anomaly detection
- Clan-level moderation tools
- Temporary or permanent sanctions

## 12. Future Enhancements

- Social feeds (updates & announcements)
- Provider livestream stats

## Summary

The Social Layer turns ProxySocialHub into:
- A **marketplace**
- A **community**
- A **trust network**
- A **shared economic system**

This design balances **transparency, privacy, security, and monetization** while encouraging long-term engagement.
